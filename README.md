# IBD_Ecotype_Analysis

本项目旨在结合 bulk RNA-seq、单细胞 RNA-seq 和空间转录组数据，研究炎症性肠病（Inflammatory Bowel Disease，IBD）中的细胞状态、多细胞生态型（Ecotype）及其空间组织特征。

> **项目状态：持续开发中**
>
> 本仓库主要用于版本控制分析代码、配置文件、环境定义、元数据结构和方法学记录。原始测序数据、大型中间文件及未发表研究结果不存储在公开仓库中。

---

## 项目目标

- 构建适用于 IBD 研究的单细胞参考图谱；
- 使用 CIBERSORTx 对 bulk RNA-seq 数据进行数字细胞计量和细胞类型特异表达重建；
- 基于 EcoTyper 识别稳定的细胞状态和多细胞生态型；
- 在独立数据集中进行验证，并探索其临床相关性；
- 结合空间转录组数据研究空间生态型及其组织结构。

## 主要数据类型

| 数据类型 | 主要用途 |
|---|---|
| 单细胞 RNA-seq | 构建细胞身份参考图谱 |
| Bulk RNA-seq | 发现细胞状态和多细胞生态型 |
| 空间转录组 | 分析空间生态型及其组织结构 |
| 临床元数据 | 开展独立验证与临床关联分析 |

具体数据集及其使用方式以项目内部的数据来源记录和分析日志为准。

## 数据管理原则

本仓库主要追踪：

- 分析脚本与配置文件；
- 软件环境与依赖定义；
- 元数据模板和数据字典；
- 人工注释与分类映射；
- 方法学及可重复性记录。

以下内容不纳入公开版本控制：

- 原始测序数据；
- 敏感或受限的临床数据；
- 大型中间文件和可重新生成的分析结果；
- 尚未发表的研究结果与主要生物学结论。

原始数据原则上保持只读，处理后的数据和分析结果写入相应的下游目录。

## 当前进展

项目目前处于单细胞参考图谱构建与分析环境准备阶段，正在推进细胞身份体系统一、参考数据整理、CIBERSORTx 输入准备以及 EcoTyper 流程验证。

后续将依次开展 bulk RNA-seq 发现分析、细胞状态与多细胞生态型识别、独立数据集验证、临床关联分析和空间生态型分析。
