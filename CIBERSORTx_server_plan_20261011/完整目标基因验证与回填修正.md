# 完整目标基因验证与回填修正

最新进展见[第九轮Group独立估计与版本疑点](Group独立估计与版本疑点.md)。本页保留第八轮借用官方Group表的实测结果，不能与第九轮独立Group输出混称。

2026-10-11，第八轮。本轮在本机完成Job24全部1249个目标基因、120样本、20类型的独立数值运行，修正名称映射和旧面板种子索引，并接上外层辅助回填。它是完整**目标集合**的验证，不是全部17,040基因的HiRes重建。入口多重检验仍使用此前完整17,040基因的统计。

**当前已能较好重建部分逐样本表达和有外部Group输入时的末端回填；仍未完成独立CIBERSORTx全流程。** 原件不变，历史结果保留，没有服务器登录或官方程序运行。

## Step1. 先修正基因名称接口

扩大到全部1249基因时，94个官方输出名称与原始输入不同，例如 `HLA-DRA → HLA.DRA`、`MT-CO2 → MT.CO2`。直接按字符串取交集会漏掉这些基因，尤其会损失部分HLA、免疫球蛋白和线粒体基因。

[输入准备脚本](../scripts/python/prepare_hires_full_target_benchmark_20261011.py)在无歧义条件下建立连字符到点的对应，检查一对一关系，原始表达与结果仍使用原始gene symbol。辅助Group表也可能使用规范化名称，因此[回填脚本](../scripts/R/reconstruct_hires_auxiliary_refill_20261011.R)显式匹配名称并拒绝碰撞。映射保存于 `full_target_benchmark_inputs/gene_name_mapping.tsv`，未通过删除无法匹配行来推进计算。

全部1249基因按已有官方任务的目标清单纳入，没有根据重建效果选基因或删除失败组合。表达来自原始CPM，fraction继续使用同一官方冻结表。

## Step2. 修正遗留随机种子索引

扩展运行的保持性检查发现：早期24基因清单中名为 `full_mixture_row_1based` 的索引实际上来自Mixture-Adjusted表。第六、七轮改用原始表达后沿用了这列，注释却称其来自原始表。这是此前工作底稿的索引来源错误。

表达输入本身完全相同；完整入口统计也没有因此改变。但worker和收缩阶段用“种子常量+行号”，所以旧行号会改变这些阶段的重抽样。**不能把这种变化归因于扩大基因集合，也不能把旧行号称作官方随机流。**

[种子检查准备脚本](../scripts/python/prepare_hires_seed_consistency_check_20261011.py)新增 `canonical_24_benchmark_inputs/`，将24个索引统一为原始完整mixture行号。旧清单和旧表达矩阵保留，种子常量、统计门槛、bootstrap次数和表达值未调整。修正后重新计算24基因，再与1249基因结果取相同行比较：**20种类型的24基因输出逐元素完全一致**。

证据：`canonical_24_benchmark_inputs/seed_index_correction.tsv`；`full_target_validation/frozen_24_vs_expanded_context.tsv` 同时保留对修正清单的零差异和对历史种子的实际差异。第七轮指标是其历史种子运行的实测结果，不能自动当作本轮统一种子的指标。

## Step3. 完整目标集合实际运行

使用现有研究脚本、相同完整基因入口统计与统一原始行号，依次完成：

1. `worker_full_target_run2/`：全局bootstrap、可检测性、两段统计和随机差异检验。1147/1249基因进入后续检测；1,100,578次NNLS，运行约97.35秒。
2. `refinement_full_target_run1/`：残差Spearman、可检测类型重估、两段收缩、弱类型残差NNLS、滑窗和OLS。835,016次NNLS，运行约53.08秒。
3. `auxiliary_full_target_run2/`：完整集合上的辅助表达回填和下限处理。输出名为 `AUX_DEPENDENT`，明确依赖外部Group表。

时间仅为本机相应R运行，不含此前完整入口统计，也不能视为官方网页或未来完整17,040基因HiRes任务耗时。新流程入口为[run_hires_full_target_benchmark_20261011.sh](../scripts/bash/run_hires_full_target_benchmark_20261011.sh)，参数：项目目录、完整目标输入目录、原始完整mixture、新输出目录、可选辅助Group表。各R阶段在Windows实际运行，Bash入口仅做语法验证，未在Linux执行。

输入目录需包含 `fractions_fixed.tsv`、`gene_selection.tsv`、`mixture_original_target_genes.tsv`。新面板清单使用原始完整mixture行号；不能把旧Adjusted行号清单直接当成统一种子的输入。辅助Group表不提供时跳过回填，避免隐式依赖官方导出。

## Step4. 回填规则已能在真实完整上下文中验证

根据此前定位的旧数值写表分支，本轮实现：

- 某类型的整个目标基因集合全为1时，不回填。
- 否则仅将最大表达恰为1的行，用显式提供的辅助Group值回填。
- 辅助值为NA时保留NA，为0或低于1时输出1；已有变化曲线不直接覆盖。

CD8_T和Endothelial在本轮完整目标集合中全为1，保护分支实际触发。CD4_T、NK、ILC、Glial在小面板中看起来全为1，扩大后存在其他可变基因，因而回填判断不同。这里的判断来自独立重建的完整输出，不再借用官方HiRes全表来决定。

**但辅助Group可靠性表仍使用官方 `GEPs_Filtered`。** 此步骤验证的是给定外部Group表时的回填行为，不能将NA一致性称为独立可靠性过滤复现，也没有直接复制官方HiRes的NA掩码。

| NA对照，24,980个基因×类型组合 | 数量 |
|---|---:|
| 官方全NA | 8162 |
| 本轮回填后全NA | 8156 |
| 双方同为NA | 8117 |
| 官方NA但本轮有限 | 45 |

剩余84个NA不一致已经保留逐条统计，不能通过照抄官方NA标记来消除。39个错误NA中30个对应官方可变表达，这也是不能把回填后的低误差中位数孤立解释成改进的原因。

## Step5. 完整面板的表达一致性与失败分支

[全目标审计脚本](../scripts/python/audit_hires_full_target_20261011.py)核对全部基因和样本顺序、名称映射、来源哈希，并分别报告独立数值阶段与依赖辅助表的回填阶段。

官方1536个可变基因×类型组合，回填前全部有120个样本的有限预测：

| 指标 | 实测结果 |
|---|---:|
| 本程序也输出变化 | 1408/1536 |
| log2(x+1)相关性≥0.95，失败项仍计入分母 | 977/1536 |
| 同一1536组合的log2(x+1) MAE中位数 | 0.087448 |
| 官方恒定，本程序误留变化 | 82个 |

这个MAE是在基因×类型组合内对120样本取平均，再对固定1536组合取中位数；不是细胞比例准确率或生物学验证。不能把小面板19/26的比例直接外推到更广泛基因。

剩余128个官方可变而本程序恒定的组合已全部定位：**68个被全局检测排除，60个进入弱变化常数重估**。阈值没有因这些失败被调低。详见 `missed_variation_branch_trace.tsv`。

回填后只有1506/1536组合仍有完整有限预测，30个缺失；这1506组合的MAE中位数为0.084307。它的分母改变了，不能与回填前0.087448直接当作同范围误差改善。全部不一致和NA诊断保存于 `full_target_validation/`。

## Step6. 数学验收与未完成部分

[R节点导出检查](../scripts/R/check_hires_refinement_checkpoints_20261011.R)已扩大到完整1249基因；[独立Python数学核对](../scripts/python/verify_hires_full_target_math_20261011.py)使用SciPy/NumPy，检查真实分界、弱类型NNLS、OLS，以及AS89穷举样例。完成记录保存在 `full_target_math_checks/full_target_math_summary.json`，逐项证据同目录。数学公式验收与官方版本一致性是两个不同问题。

实际完成：22,940个残差Spearman检查、1147个基因收缩恒等式、1147个分界目标检查、1147个弱类型NNLS和1529个OLS均通过相应公式/目标验收；OLS最大相对预测误差1.50×10⁻¹⁴。3个n=8的AS89样例各穷举40,320个排列后通过。分界索引的严格一致性另按下面的并列最优情况记录。

严格分界索引检查中，1135/1147基因与SciPy一致，12个基因的最优分界相差一行。进一步检查发现，移动的那一行在可变类型设计矩阵中全部为0，因此其平方残差不依赖拟合系数，移到另一段也不改变理论总RSS。两种分界的RSS差仅为浮点舍入量，按表达平方和归一后最大约3.25×10⁻¹⁶。这是结构性并列最优，不是普遍的下标错位。

保留了首次严格失败表 `strict_split_first_attempt.tsv`；追加的验收条件只允许“移动行确为全零设计，且目标差不超过10倍机器epsilon×表达平方和”的并列情况。没有改R分界算法或选择与官方更接近的分界。分界索引不逐项相同的限制仍存在，段大小变化也可能影响后续随机抽样，因此不将其解释为官方随机流等价。

当前优先缺口已明确：完整Group估计和可靠性过滤必须独立重建；入口q与官方内部版本差异、68条检测漏检、60条弱变化回填及随机流要继续核对；末端84个NA差异与82个错误可变行仍需追踪。独立signature、fractions和S-mode仍未完成。

初次输入检查、数学保持性检查和辅助名称检查曾中止运行，均在诊断后使用新输出目录重跑。失败目录只留少量入口环境信息，未当作有效结果、未删除历史文件。正式discovery/recovery未使用这些研究输出。
