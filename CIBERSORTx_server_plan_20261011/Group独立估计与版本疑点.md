# Group独立估计与版本疑点

2026-10-11，第九轮。本轮继续阅读缓存Docker应用层的Group R函数、C++调用桥和原论文补充方法12.2，在本机新增独立Group估计及过滤，并接入此前的1249基因HiRes结果。原始研究输入、官方结果与此前运行均保留。

**现在能够在给定冻结fraction后独立生成Group辅助表，计算阶段不再必须借用官方Group表。但输出尚不能称为官方等价，NA一致性仍明显不足。** 官方fraction仍是上游依赖，signature、fractions和S-mode未独立实现；没有运行官方二进制或更改认证逻辑。

## Step1. 阅读证据与分支区别

论文来源为[Newman等，Nature Biotechnology 2019](https://www.nature.com/articles/s41587-019-0114-2)，本轮使用已有原始补充方法缓存12.2。缓存R函数来自已保存Docker应用层，`runR::CIBERSORTxGEP`静态伪代码显示它调用Rscript；这说明旧镜像Group走R桥接，不能据此判断当前网页版本一致。证据路径和SHA保存于本轮manifest，供应商原件只作本地审阅。

Group采用30次、75%样本无放回NNLS，log(coefficients+1)空间中位数、几何CV及bootstrap SD。HiRes入口采用此前定位的2/3样本抽取和不同的marker排斥规则，二者分别计算，不能互相替代。

缓存R片段有两个版本疑点：

- `vY0 <- g`中的g是最后一次抽样的90个表达值，`mX0 <- weights_subset`却含完整120行。R会将短向量回收到120行，既改变顺序也重复部分值，无法当作正确的逐样本残差。本轮独立实现使用完整、顺序一致的120值残差，并显式记录这项差异。
- 原论文强marker规则将其他q>0.25系数置0；缓存R片段写置1。Job24未过滤Group中没有恰好为1的系数，但该任务没有q<1e-5基因，因而分支根本未触发，**不能用它证明网页采用哪一种置零/置一规则**。研究实现选择论文置0规则，未声称复刻网页。

`GEPs_StdErrs`的缓存实现保存的是bootstrap系数SD，不是t检验使用的解析SE。本轮分别输出这两个对象，避免后续误用。

## Step2. 先做条件公式验证

仅给定官方17040×20 CV表，根据缓存代码的排序、75分位截断、归一化rank、几何距离与`CV>=threshold`边界独立重算过滤：**340800个组合的NA标记全部一致**。20个阈值保存于`group_independent_validation/official_CV_conditional_filter_check.tsv`。

同样，仅给定官方P表，在每个类型的16982个非缺失基因上独立BH，缺失恢复为q=1：与官方Q最大误差1.43×10⁻¹³。这是过滤和BH公式的条件验证，不能称为独立CV/P估计已经与官方一致。

缓存CV几何实现与补充方法文字的坐标/距离描述存在表述差别；本轮保留缓存计算式，未因文字歧义另换一套阈值。

## Step3. 独立Group真实运行

[Group研究脚本](../scripts/R/reconstruct_group_expression_20261011.R)读取原始CPM和同一冻结fraction，使用逐基因独立L'Ecuyer-CMRG随机流，完整17040基因、120样本、20类型，完成511200次NNLS。实测包含保存的脚本计时59.78秒，仅代表本机此阶段。

输出于`group_independent_run1/`：未过滤表达、过滤表达、CV、P、Q、bootstrap SD、解析SE、marker处理前beta、阈值、检查点及环境。BH和阈值均在完整基因范围计算，不对子集重新校正。

marker处理前系数与官方Group的20类型log2(x+1)相关性中位数为0.986873；但这只是跨基因相关性，不能证明逐值相同或解卷积准确。处理后强marker置零会造成较大差异，CV过滤NA也有30917个不一致，约占全部组合9.07%。未通过删除差异或复制官方掩码修正。

以各类型P值平均绝对差再跨类型平均，完整残差对官方差为0.088809，回收诊断为0.023715；两者都没有逐值一致。这支持“统计残差实现可能解释部分版本差异”的调查方向，**不证明当前网页实际用了该疑点代码**。诊断P/Q只保留为比较材料，不进入Group或HiRes主计算。缓存片段未被直接执行。

## Step5. Group接入HiRes后的实测结果

此前worker及收缩表达原样复用，新Group过滤表作为唯一辅助表进入外层回填，结果另存`auxiliary_independent_group_run1/`，不覆盖借用官方Group的上一轮结果。名称映射、整类型全1保护与下限处理保持不变。

## Step6. 数学核对与流程入口

[检查点导出](../scripts/R/export_group_math_checkpoints_20261011.R)和[Python独立验收](../scripts/python/verify_group_math_20261011.py)在24个预先均匀选定基因上重新计算720次SciPy NNLS，最大相对系数差6.49×10⁻¹³；120项beta/CV/SD/解析SE/P统计核对通过。完整340800组合的BH、marker规则和过滤检查也通过。此处验证研究代码的数学一致性，不验证官方随机流或生物学正确性。

新增[固定fraction后的研究入口](../scripts/bash/run_fixed_fraction_expression_research_20261011.sh)：Group→HiRes入口→worker→收缩→Group辅助回填。它不再隐式读取官方Group，仍要求外部fraction和规范化目标清单。R各阶段已本机实际运行；Bash只做语法检查，尚未在服务器/Linux端整合执行。

下一步优先定位Group抽样/随机流与CV估计的差异，并继续区分论文、旧镜像与现行网页统计分支，再处理HiRes的检测和弱变化偏差。保持公式正确的研究主线与旧版本诊断分开，不能为追求数值相似把可疑回收残差默认为正式方法。
