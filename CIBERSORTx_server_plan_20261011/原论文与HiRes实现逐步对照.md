## Step1. 阅读材料及定位

主文：[Newman et al., Nature Biotechnology 2019](https://www.nature.com/articles/s41587-019-0114-2)，DOI 10.1038/s41587-019-0114-2。全文 XML 来自 Europe PMC 官方接口；完整 43 页补充 PDF 来自[出版社公开附件](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41587-019-0114-2/MediaObjects/41587_2019_114_MOESM1_ESM.pdf)。Supplementary Note 1 中 12.2、12.3、12.4 分别描述 group-mode、HiRes 和批次校正。

PDF 第 36、37 页（印刷页码 35、36）已渲染并目视核对收缩公式、滑窗矩阵和线性校准。原文保留在本地 `paper_methods`，加入本机 Git 排除；源摘要与章节定位可见 [paper_supplement_provenance.json](paper_supplement_provenance.json)。没有将出版全文当作项目原创代码重新发布。

EcoTyper 下游语义参考 [Luca et al., Cell 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8526411/)。该文明确允许已有其他来源的细胞特异表达进入后续步骤。因此，“来自 BayesPrism”本身不能证明输入必然错误；应检查实际 G 的估计含义、样本差异、类型特异性和泄漏。此次其 Europe PMC XML 返回 HTTP 500，仅用可检索的原文页面核对这一接口语义，没有宣称重新取得完整全文。

## Step2. 原论文八步与代码的对应

每一步的函数、文件和实际行号存于 [paper_code_step_crosswalk.tsv](paper_code_step_crosswalk.tsv)。以下为方法概括，不是逐字复制原文。

| 步骤 | 原论文方法 | 固定旧镜像证据 | 目前判断 |
|---|---|---|---|
| 1 | bootstrap 全局表达；合并经验概率和校正统计值，判断可检测性 | 系数中位数、非正频率、BH 辅助表、Fisher 合并；全基因 BH 在 gene subset 之前 | 大部分对应；零概率替换和入口默认次数另核对 |
| 2 | 每基因将 bulk 表达升序排列 | 同步重排比例矩阵样本行 | 已对应；排序不使用疾病或炎症标签 |
| 3 | 两段 NNLS，选择最小 RSS 的切点 | `findBestRSSThres`；部分样本规模下调整搜索边界 | 骨架对应，边界不能只照论文文字近似 |
| 4 | bootstrap Z 检验、50 次随机参考，再合并显著性 | Z 分母为两段 SD 平方和的平方根；50 次随机参考与 Fisher | 基本对应；随机化范围、经验尾概率细节存在差异 |
| 5 | 剔除不显著类型后重拟合；按差异置信度收缩两段表达 | 比例列置零、重拟合、平方权重收缩、弱变化替换 | 收缩公式已对应；备用检验和罕见类型规则见下文 |
| 6 | 各滑窗 NNLS，补边缘后平均 | 每窗 5 次 bootstrap；首尾各补 W−1 行 | 已对应；正文补最后行写成 row c，代码取最后有效窗口行 |
| 7 | 用两段参考作为锚点，OLS 调整平滑表达幅度 | 线性回归、标准差 0.001 的参考扰动 | 校准方向对应；随机序列及跨线程状态未验证 |
| 8 | 恢复原样本顺序，保存逐类型表达 | worker 逆排序、外层再处理标签和输出 | 排序已可追踪；最终过滤开关的网页对应仍未知 |

这说明 HiRes 不是对每个样本独立做一次 NNLS。它利用整批样本的表达排序、比例变化和窗口结构推断样本级表达；保持同一完整输入而只指定目标基因，与改变整张输入矩阵分别运行，不是同一计算。

## Step3. 核对最关键的表达收缩

Supplementary Note 1，12.3.6：令差异证据变换为 `v = −log10(pdiff)`，按上调、下调方向分别归一化并限制权重不超过 1。两段表达的调整量为：

`delta = (1 − weight²) × abs(g1 − g2) / 2`

低的一段加 delta，高的一段减 delta。因此调整后两段的绝对差为 `abs(g1 − g2) × weight²`，中点不变。weight=1 保留差异；weight=0 将两段并到中点。这是算法的主动约束，不等于程序未正常运行。

本轮为分析器补齐 17 个 vector 算术/归约函数的隐藏结果指针，另存 [新补参 runHiRes](decompiled_numeric/CIBERSORTxHiRes_refinement_typed/runHiRes_typed.c)。其减法、绝对值、除以 2、平方、乘法、再减法，与上述公式一致。所有类型修改仅发生在 Ghidra 内存会话，`-readOnly` 日志确认丢弃修改；没有覆盖 ELF 或先前自动导出。

论文默认将收缩后倍数 <1.1 的弱变化替换为全局表达或 NA。旧镜像中实际可见的倍数是：

`fold = (max(g1_adjusted, g2_adjusted) + 1) / (min(g1_adjusted, g2_adjusted) + 1)`

进入当前弱变化集合还要求权重不等于 1、全局表达 >0。被纳入的类型随后有针对性的残差 NNLS 重估，不能把它们全简化为“立即换成最初的全局中位数”。这是新发现的运算细节。

例如 1 对 1.15 原始比为 1.15；加 1 后为 2.15/2=1.075，可能进入弱变化替换。100 对 115 加 1 后为 116/101≈1.149，仍高于阈值。因此该规则在低表达区更强；后续实现必须保留表达单位和处理顺序。

## Step4. 论文文字和旧编译版本不能直接画等号

| 项目 | 论文说明 | 旧镜像可读行为 | 后续实现要求 |
|---|---|---|---|
| 备用差异证据 | 控制其他类型贡献后的 Pearson 相关 p 值 | 调用 `stats::spearmanCor`；其内部排名并返回双侧 p 值 | 不能按论文名称直接替换旧版本；建立两条版本证据 |
| 弱差异倍数 | fold change <1.1 | 两端都加 1，再比较 <1.1；还有权重和全局表达条件 | 保留 +1、严格小于以及额外条件 |
| 显著性刻度 | `−log10(alpha)` | 该常量精确为 1.3010299956639813，即 `−log10(0.05)` | 不近似为随意阈值 1.3 |
| 随机参考尾概率 | 绝对随机差超过观测差的频率 | 保存带符号的 bootstrap 差；排序/方向处理后选最接近观测差的位置，算 `1−(index+1)/50`，零值改 1/50 | 不直接换成通常的超过次数；还需核对 randomizeInCols 与 MATCH_R 路径 |
| 窗口边缘 | 补充正文写第二矩阵补 row c | 代码使用最后有效窗口行；Q 的行数是 N−W+1 | 记录可能的正文笔误，不能让错误索引进入实现 |
| 额外恒定类型 | 补充材料没有明确列出该分支 | 用比例表列均值找最小平均比例类型；若其变化方向与更高比例类型相反，指定最小集合最终覆盖为全局代表表达 | 这是版本特定证据，完整可靠性意义未经过外部输出验证 |

上述“不同”不自动意味着作者错误或网页错误。原论文发布、旧镜像构建、当前网页更新可能对应不同版本；现在能断言的是不能把论文概述和一个旧 ELF 混合成未经核对的唯一实现。

## Step5. 外层导出规则继续补齐了哪些

旧主调度 `CIBERSORTxHiRes` 的可见写表路径包括：可选读取辅助表并重排基因；部分全 1 估计行回填辅助表表达；再次把表达下限设为 1；根据一个布尔实参，在当前类型保留跨样本 `max−min >0.1` 的行，再写文件。

已读取固定 ELF 对应常量 0.1，但尚未确认该布尔实参在当前网页对应哪个选项，也未核对辅助表的外部文件身份。因此只能称为已定位的旧版本输出分支，不能断言所有网页 HiRes 都启用，或把它称为 group-mode 的自适应 geometric CV 过滤。

Supplementary Note 1 的 12.2 对 **group-mode** 描述自适应 geometric CV 噪声阈值；12.4.3 又明确说明 **S-mode 调整 signature** 的 NNLS 不需要该自适应过滤。HiRes 的 pglobal/pdeg、表达收缩、恒定替换和外层输出处理应另行记录。这三个场景不能套用同一过滤模板。

## Step6. 对本项目和后续可实现程序的意义

1. **为什么 HiRes 恒定行可能很多。** 论文和代码均存在主动压缩弱变化的机制；恒定行不必然是运行失败。要解释之前基因块，仍需实际输出与日志，不能仅凭当前源码归因。
2. **为什么 120 例能跑，却不保证 20 类都能稳定解析。** 除总样本数外，还依赖比例矩阵的可辨识性、每个窗口的类型信号和 bulk 中的表达变化。稀有类型、高度相关比例和区域效应可能削弱这些条件；这是依据模型结构的推断，未作本项目定量验证。
3. **为什么基因块不能直接随意拼。** 必须核对共同样本、完整预处理基因范围、比例表、BH 范围、随机流及最终导出规则。仅按相同文件名/维度拼接不足以证明来自同一全局估计。
4. **为什么官方路径不自动保证肠道生物学准确。** 该算法依赖上游参考质量，且通过启发式约束解欠定问题；使用 CIBERSORTx 不等于证明每个细胞状态是真实生物状态。仍要检查类型特异 marker、区域混杂、可变基因覆盖和独立 recovery。
5. **下一步实现顺序。** 先固定一个数值版本，完成随机化和输出开关；实现独立的小数值模块并与合法取得的官方小输出比较。通过后才能组装 EcoTyper 的 gene×sample×cell-type 接口。本轮没有制作一个可以直接替代正式分析的程序。
