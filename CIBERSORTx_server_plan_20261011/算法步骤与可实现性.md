2026-10-11，第二轮数值调查。本机静态分析官方固定镜像，未运行供应商程序，未连接服务器，未修改认证机制或研究数据。本记录将可读原始 R、反编译证据和独立数学核对分开；不是完整 CIBERSORTx 实现。

第三轮更新：参数 ABI、辅助统计表、平滑边缘和输出下限见 [HiRes 接口与输出审计](HiRes接口与输出审计.md)。其中更正了此前对辅助表的临时理解，并另存补参后的分析版本；以下保留第二轮调查时的阶段记录。

## 本轮新增的实质内容

数值伪代码现在为 HiRes 171 个函数、两个 Fractions 版本各 258 个函数，总计 687 个导出记录，比上一轮增加 105 个。数量包含模板、求解器和版本重复，不能解释为恢复比例。补充了抽样、排序、矩阵运算、列提取、输出、NNLS 的低层依赖，以及此前暂未导出的 signature 构建主体。

从已固定摘要的 ELF 反汇编中核对 84 处浮点常量引用，保留指令地址、目标地址、原始小端字节与解释值：[常量证据](hires_numeric_constant_evidence.json)。此步骤只读取指定数值函数引用的 `.rodata`，没有扫描或输出账户凭据。

阅读顺序：本记录 → [核心函数阅读目录](数值源码阅读目录.md) → [完整函数索引](numerical_source_index.tsv) → 对应原始 R 或伪代码。全部函数摘要见 [覆盖与来源验证](source_recovery_validation.json)。

## Step1. 先明确数值对象和矩阵方向

设样本数为 N、细胞类型数为 C。单个基因的混合表达为长度 N 的向量 y，比例矩阵 F 为 **样本 × 细胞类型，N × C**。群体代表表达 β 为长度 C 的向量。

基础子问题为 `min ||F β − y||²`，约束 `β ≥ 0`。这里不约束 β 的和为 1，因为 β 是表达量；比例矩阵的行和与表达系数是不同对象。

| 对象或操作 | 静态证据 | 已能判断的语义 |
|---|---|---|
| Table 数值矩阵 | `Table::resize`、`nRows`、`nCols`，数值容器位于对象中 `+0x50` 的位置 | 外层 vector 对应行，内层 vector 对应列；此偏移是当前二进制对象布局，不是通用接口 |
| 全矩阵 NNLS | [nnls，00125f35](decompiled_numeric/CIBERSORTxHiRes/numeric_00125f35.c) | 外循环列、内循环行，将矩阵按列展开 |
| 行子集 NNLS | [subsetNNLS，001261f9](decompiled_numeric/CIBERSORTxHiRes/numeric_001261f9.c) | 同一索引同时提取 F 的行和 y 的元素，允许重复索引 |
| 低层求解 | [nnlsFTWrapper，00125d3f](decompiled_numeric/CIBERSORTxHiRes/numeric_00125d3f.c) → `lh_nnls_` | 向低层传入行数、列数和列优先矩阵；输出长度为 C 的系数 |
| 表达入口 | `runHiRes` 从 GETable 按基因行读取混合表达；主调度给比例表提取前 C 列 | 混合表达为基因 × 样本，比例为样本 × 细胞类型 |

`Table::nRows/nCols` 被 Ghidra 显示成 `void`，但调用者把返回值用作维数。这就是反编译类型丢失的实例，不能照伪代码声明直接编译。`runHiRes` 的两个 double 实参也未完整恢复，需要按照 ELF 符号签名和调用者核对，而不能直接沿用 `param_*` 命名。

## Step2. HiRes 的 bootstrap 已经可以写出明确规则

联合 [doBootstrap，0010c9f7](decompiled_numeric/CIBERSORTxHiRes/numeric_0010c9f7.c)、[utility::sample<int>，00136871](decompiled_numeric/CIBERSORTxHiRes/numeric_00136871.c) 和二进制常量证据，可确认以下原生分支：

1. 输入行范围是 C++ 的 `[start, end)`，实际索引为 start 到 end−1。
2. replacement 为 true：抽取 `end−start` 行，有放回；每次抽取用均匀整数分布。
3. replacement 为 false：先打乱索引，无放回取 `int((end−start) × 2/3)` 行。这里 int 截断发生在正数上。
4. 把相同索引交给 `subsetNNLS`，得到一组 C 维表达系数。
5. 重复 B 次，输出 **B × C** 矩阵。这个函数不自行取均值或中位数；聚合由调用者决定。

常量 1 的实际地址为 `0x22a1c8`，2/3 为 `0x22a290`。Ghidra 把前者显示成 `_LAB_0022a1c6_2`；本轮用 RIP 相对浮点读指令核对真实地址，避免按重叠符号名称猜偏移。

已经查看的 `runHiRes` bootstrap 调用传入 true。不同位置使用输入重复次数，也有明确的 5 次抽样和 50 次随机表循环；不能把所有环节都当作同一个 repeats 参数。另有 `MATCH_R` 分支，使用 R 的 L'Ecuyer-CMRG。相同种子下，R 与 C++ 随机流不能默认等价。

这与参考矩阵构建时按供者、部位抽取单细胞无关：这里抽的是表达推断子问题中的样本行。

## Step3. 窗口和分割点已经得到可核对的表达式

在 [CIBERSORTxHiRes，001144fc](decompiled_numeric/CIBERSORTxHiRes/numeric_001144fc.c) 中，空窗口参数触发自适应计算。常量 `0x22a2e8` 已确认是 4，`0x22a268` 是 2，因此当前固定镜像的规则为：

`W = ceil(max(C + 1, min(N / 2, 4 × C)))`

N=120、C=20 时得到 W=60。显式提供窗口时另走读取和取整分支。本记录不是对当前网页默认值的实测；旧镜像与网页不能直接视为同一版本。

基因表达排序后，比例表按同一索引重排。[findBestRSSThres，001268b2](decompiled_numeric/CIBERSORTxHiRes/numeric_001268b2.c) 在 `min(b, N−b)` 到 `max(b, N−b)` 的候选位置逐点计算：

`RSS(s) = NNLS 残差平方和[0:s] + NNLS 残差平方和[s:N]`

严格小于当前最优值才更新；返回 `ceil(max(b, 最优分割点))`。`runHiRes` 先令 b=W，如果 `N−2W < 10` 则令 b=W/2。因此 120/20 默认窗口示例中，分割点搜索使用 b=30，不能直接把 W=60 当成这个阶段唯一的候选点。

排序函数已导出，但其中包含 −1 哨兵、NaN 判断和未完全恢复的 pair 返回值。普通有限值的排序逻辑可追踪；缺失值、哨兵与并列值处理仍需核对机器指令，尚未宣称逐个分支都准确恢复。

## Step4. 平滑与幅度校准已有证据，完整拼接仍需逐段确认

`runHiRes` 后段包含滑动窗口 bootstrap、前后对齐的表达矩阵、两组结果相加除以 2、边缘复制和线性回归。还包含标准差 0.001 的随机扰动，及两段表达差超过 1e−5 才进入校准的条件。

回归的三个小函数已经能明确解释：

| 函数 | 数学语义 |
|---|---|
| `LinearRegression::calcSlope` | `cor(x,y) × sd(y)/sd(x)`；任一标准差为零时斜率为 0 |
| `calcIntercept` | `mean(y) − slope × mean(x)` |
| `predict` | `slope × x + intercept` |

本轮恢复了 [列提取 mCol](decompiled_numeric/CIBERSORTxHiRes/numeric_00123dff.c) 和矩阵算术依赖，使这些操作的方向可以进一步追踪。但窗口边缘填充、非显著类型屏蔽、回归后取值限制和恢复原样本顺序的完整组合，仍不能仅凭函数名推断。

原论文明确区分群体代表表达与样本级表达，作为这里的科学方法来源；上述具体常量和规则来自固定镜像静态证据，不能倒过来全部归给论文。[Newman et al., Nature Biotechnology 2019](https://www.nature.com/articles/s41587-019-0114-2)

## Step5. 原始 R 中已经能沿用什么

| 原始可读内容 | 可实现程度 | 仍需确认 |
|---|---|---|
| `run_SVR.R` | e1071 线性 nu-regression 和权重提取明确 | C++ 外层归一化、多个 nu 的选择和比例后处理 |
| `run_optimization.R` | 各类排名前 G 基因取并集，再用 kappa 选 G 明确 | 上游 DE 排名、输入归一化和其余 signature 构建步骤 |
| `runCIBERSORTxGEP` 与 GEP 的 `res` | 有原始 R 函数和行号来源 | 全局对象、日志变换、抽样后统计量维数及辅助依赖 |
| S-mode 的 R 辅助模块 | 实际校正辅助源文件已取得 | C++ 外层构造的伪混合、缩放、基因匹配和再次求比例 |

GEP 的 `res` 原文先无放回抽取约 75% 的样本做 NNLS，和 HiRes 原生有放回 bootstrap 不同，不能互换。其统计量部分出现 `vY0 <- g`（抽样后的表达向量）和 `mX0 <- weights_subset`（完整比例矩阵）的组合；这是原始文本中可见的维数疑点，尚未对原程序验证，不能悄悄修正后声称完全复现。完整片段见 [GEP res](vendor_reference/R_function_fragments/hires_f0bfeaddfa2e_res.R)。

原始优化函数写 `kappa(BG.comb.xpr, exact <- T)`。本机 R 方法签名及独立核对显示，第二位置实参传给 exact，与 `exact=TRUE` 的数值相同；不能因为写法奇怪就误报参数错误。

### Signature 构建主体本轮也已取得

此前 `buildSignatureMatrix` 未导出，原因是保守筛选把 `GETable::rmTokensAndIG` 中的 Tokens 当作凭据标记。独立诊断确认它是代码标识符，进一步检查其主体发现：读取基因标签、判断标签中的 `-` 与 `IG`、重建标签和表达行，没有认证操作。筛选只针对这一完整标识符作精确例外，其余认证规则保持；导出代码本身没有替换或改写。[误判诊断](signature_screening_kind.tsv)

现在可以直接阅读 [HiRes 内附 Fractions 的 buildSignatureMatrix](decompiled_numeric/CIBERSORTxFractions_hires/numeric_0010dd29.c)。其中计算顺序已能追踪为：

1. 读表达和 phenotype classes，处理基因标签并排序。
2. 根据输入数值范围作日志相关变换；按选项进行 QN，另保留反日志表达对象。
3. 按类别标记取两组列，计算行均值、标准差、线性空间中位数、两侧尾概率和 FDR。
4. 依次筛选 p 值、logFC/q 值，按 logFC 排序，保存各类型的候选基因。
5. 遍历 G 的候选范围，以 kappa 选择数量；取各类型前 G 个基因的并集。
6. 限定到该基因集，计算 SVD，写出 signature 和热图。

这使 signature 主流程与原始 `run_optimization.R` 能接上。具体统计量的自由度、极端数值、过滤阈值及并列排序仍需逐项核对，不能仅凭上述顺序宣称重构已完成。`rmTokensAndIG` 当前伪代码显示只有标签同时含 `-` 与 `IG` 才排除，不能将该版本行为概括为删除全部免疫球蛋白或 TCR 基因。

HiRes 的 R 桥接函数提到 `run_bootstrap.R`、`run_randTable.R`、`run_qtmpAddRnorm.R`，但完整 HiRes 层目录中未匹配到这三个文件名。原生计算分支已取得伪代码；R 匹配分支的外部模块不能标为“源码已完整取得”。

## Step6. 实际完成了哪些检查

[独立 R 核对脚本](../scripts/R/check_cibersortx_numeric_contract_20261011.R) 使用八样本、三类型的人造矩阵，只核对数学与接口理解，没有载入或执行供应商函数。

| 检查 | 结果 | 证据范围 |
|---|---|---|
| 列优先展开与重建 | 误差 0 | 矩阵存储解释可自洽 |
| 重复行索引同时应用于 F 和 y | 表达真值恢复误差约 5.3e−15 | 子集方向和重复行不应错配 |
| 小矩阵 NNLS 活跃集合穷举 | KKT 误差约 2.3e−15 | 非负约束数学条件正确，不是供应商求解器验证 |
| 120 例、20 类默认窗口公式 | 60 | 公式代入正确 |
| kappa 第二实参 | 与显式 exact=TRUE 相同 | 原始 R 调用语义核对 |

结果表：[independent_numeric_contract_checks.tsv](independent_numeric_contract_checks.tsv)。环境：[R sessionInfo](numeric_contract_R_sessionInfo.txt)。这些检查不能证明完整 HiRes 重构已成功，也没有检验已上传研究样本的数值等价性。

## Step7. 接到 EcoTyper 前仍需完成的工作

EcoTyper 官方 worker 的接口包含 mixture、classes、cibresults 和线程数；Docker 与 Singularity 入口均仍传运行凭据。它是调度接口，不包含 HiRes 数值实现。[官方 csx_hires_worker.R](https://github.com/digitalcytometry/ecotyper/blob/master/pipeline/csx_hires_worker.R)

后续如实现独立算法，应首先把上述小数值模块与完整统计分支区分开：恢复丢失类型和双精度实参 → 确认排序/过滤/窗口边界 → 确认全局状态与随机流 → 用授权获得的官方小规模输出核对 → 按细胞类型输出统一的“基因 × 样本”矩阵。样本顺序、基因标识、过滤值和表达空间都应有明确记录。

本轮已经有可供独立科学实现参考的数值步骤；尚未得到完整作者源码或经过验证的替代程序，也没有解决官方运行 token 审批。保留供应商静态材料在本机的 Git 排除目录，自写审计脚本和方法记录分别保存。
