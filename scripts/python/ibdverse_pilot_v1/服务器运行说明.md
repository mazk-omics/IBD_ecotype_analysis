本地已完成脚本准备与模拟数据验证。尚未在服务器提取真实细胞，也未运行网页。使用现有 ibd_refaudit 环境（h5py、numpy、pandas），不需要 Scanpy、AnnData 或 omicverse，不修改原 H5AD 和已有脚本。

## 上传与启动

把本目录旁的 ibdverse_cibersortx_pilot_v1.tar.gz 上传到服务器 /home/mazekai/IBD_EcoTyper。包内脚本位于独立 scripts/python/ibdverse_pilot_v1 子目录。

```bash
tar -xzf /home/mazekai/IBD_EcoTyper/ibdverse_cibersortx_pilot_v1.tar.gz \
  -C /home/mazekai/IBD_EcoTyper

bash /home/mazekai/IBD_EcoTyper/scripts/python/ibdverse_pilot_v1/run_pilot.sh
```

脚本默认使用已完成的 20261006_161527 审计目录及已确认的 Full_cohort.h5ad 路径。若审计目录改过名，将 label_category_sample_donor_coverage.tsv 的绝对路径作为 shell 脚本第一个参数。所有输出写入新建的带时间戳目录，日志位于其旁边；已有非空输出目录不会覆盖。

## 此轮抽样与验证范围

- 18 个候选类型各 200 个细胞，共 3,600 个网页参考细胞。每类健康未炎症 100、CD 炎症 50、CD 未炎症 50，按供者平衡，最多 5 个细胞/供者/类型。
- 固定种子 20261006，按疾病/炎症层预留整位供者约 20% 作后续验证。已用真实聚合表预检：274 位训练供者、68 位预留供者；18×3=54 层配额均可行。源逐细胞 QC 后的实际配额由服务器脚本再次检查。
- 另外提取两个待定 T 标签各最多 60 个训练细胞作身份诊断。这至多 120 个细胞不进入网页参考输入，不强行归入 CD4、CD8、NK，也不建立 T_other 列。
- 沿用作者既有标签，采用有限、正值等基本有效性检查。不额外套用全局 n_genes/线粒体/conf_score 生物学阈值；输出分布供审阅。可选 --min-conf-score 仅在已理解该值含义后使用。此轮不重新做全量聚类、双细胞或环境 RNA 分析。
- 从 layers/counts 仅读取选中行，检查所有选中 counts 的非负有限整数性；网页只按 128 个基因一块写出，不把百万细胞表达矩阵稠密化。
- 网页输入暂排除重复 symbol 的全部条目，并去除抽样后全零基因。包含 RGS5、SOD2 等歧义位点的原始选中 counts 全部保留在 selected_counts.h5，身份诊断按每个 locus 分别报告，便于后续修订。

供者预留是单细胞参考的内部验证设计，不是 MSCCR recovery 分析。

## 产出与下载

输出根目录：/home/mazekai/IBD_EcoTyper/03_reference/ibdverse_cibersortx_pilot/output/pilot_时间戳

先下载 small_audit_reports.tar.gz 到本地项目：它包含 summary.json、运行参数、训练/预留供者名单、细胞清单、原始标签组成、供者贡献、QC 和按类型×疾病/炎症分层的身份基因表达诊断。这样可直接继续审阅，不必下载原始 25 GB H5AD。

主要文件：

| 文件 | 用途 |
|---|---|
| IBDverse_TI_18types_scRNA_reference.txt.gz | 网页参考输入的压缩副本；下载后解压为 .txt 上传 |
| IBDverse_TI_18types_scRNA_reference.txt | 非对数 raw counts，基因×3,600 单细胞，列名如 CD4_T.1 |
| selected_cell_manifest.tsv | 网页列名、源细胞行号/ID、供者、原标签、分组、QC、是否为诊断专用细胞 |
| selected_counts.h5 | 选中细胞的完整原始基因 CSR counts；自定义 HDF5，**不是 AnnData h5ad** |
| gene_export_manifest.tsv | 全部源基因、网页是否保留以及排除原因 |
| marker_expression_summary.tsv | 候选身份基因表达和检出率；诊断面板不用于自动确定身份或过滤全基因 |
| sampling_capacity.tsv | 训练供者/QC 后每一层的实际可用数量与抽样结果 |
| donor_split.tsv | 训练和预留供者；供者级划分对所有类型一致 |
| summary.json | 输出维度、核查统计、运行时间和输入文件校验和 |

原 counts 与 obs.total_counts/n_genes 的吻合程度会报告；若不吻合，先检查 QC 是在哪个基因集合上计算，不默默强制等同。网页的 CPM 归一化与诊断表按完整 source counts 总量算的 CPM 分母不完全相同，诊断表不作为网页特征矩阵。

## 网页设置

下载并解压 txt.gz，上传 File Type 选择 Single Cell Reference Matrix，然后 Create Signature Matrix → Custom → scRNA-Seq；首轮命名 IBDverse_TI_pilot18_v1，禁用 quantile normalization，Min. Expression 0.5、Replicates 5、Sampling 0.5。输入 raw UMI counts、列头的类型加数字后缀遵循作者教程。[CIBERSORTx 输入格式说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC7695353/)

先审阅 small_audit_reports 中的抽样/QC/身份结果，再将其用于后续分析。summary 的 biological_identity_review_complete=false 表示脚本没有把诊断自动判定为“身份已验证”。网页运行成功也不等于参考在 bulk 中已准确，后续需要预留供者验证。

这一 .txt 是网页构建 signature matrix 的**输入**。网页输出 signature matrix、参考/phenotype 中间文件和热图后，下载保存，再用相同抽样细胞与自建矩阵作比较。此轮还不执行 MSCCR bulk 反卷积或 EcoTyper 重跑。
